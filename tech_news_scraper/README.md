# 科技AI资讯抓取工具

自动抓取最新科技和AI领域新闻资讯，提供中文版本的全球科技热点。

## 功能特点

- 支持7个中文科技/AI资讯来源
- 涵盖AI科技、国际热点、国内科技动态
- 自动过滤技术教程类内容
- 每次精选20条最新热门新闻
- 自动保存到 `news` 目录

## 使用方法

```bash
# 进入目录
cd tech_news_scraper

# 安装依赖（首次使用）
pip install -r requirements.txt

# 运行工具
python3 main.py
```

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-c, --count` | 显示/保存资讯数量 | 20 |
| `-d, --detail` | 是否抓取新闻详情 | 否 |
| `-o, --output` | 输出文件名 | 自动生成 |

## 示例

```bash
# 获取20条资讯（默认）
python3 main.py

# 获取10条资讯
python3 main.py -c 10

# 获取5条资讯并抓取详情
python3 main.py -c 5 -d

# 指定输出文件
python3 main.py -o custom_news.json
```

## 定时任务

可以使用 cron 设置每日自动抓取：

```bash
# 编辑 crontab
crontab -e

# 添加定时任务（每天早上9点运行）
0 9 * * * cd /path/to/tech_news_scraper && python3 main.py
```

## 过滤机制

系统自动过滤包含以下关键词的内容：
- 教程、最佳实践、手把手
- 入门指南、实战、基础
- 零基础、保姆级 等技术教程类标题

优先推送：
- AI和科技领域最新动态
- 全球科技热点新闻
- 科技产品和创新资讯
