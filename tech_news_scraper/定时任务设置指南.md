## 方法二：使用macOS自带的"日历"应用

### 步骤1：打开日历应用
- 打开「日历」应用（在启动台或应用程序文件夹中）

### 步骤2：创建新事件
- 点击左上角「+」按钮创建新事件
- 设置事件名称：`科技新闻自动抓取`
- 设置时间：每天 8:30 AM

### 步骤3：添加提醒
- 点击事件详情中的「提醒」选项
- 选择「自定义」
- 添加「打开文件」提醒，选择：
  `/Users/zhuxingchong/Documents/trae_projects/NovelToSpeechAutoTool/tech_news_scraper/run_daily.sh`
- 设置提醒时间为「事件发生时」

### 步骤4：设置重复
- 在事件详情中设置「重复」为「每天」

## 方法三：使用Automator创建定时任务

### 步骤1：打开Automator
- 打开「Automator」应用

### 步骤2：创建新工作流
- 选择「应用程序」类型

### 步骤3：添加操作
- 在左侧搜索「运行Shell脚本」并拖到右侧
- 设置脚本内容：
```bash
cd /Users/zhuxingchong/Documents/trae_projects/NovelToSpeechAutoTool/tech_news_scraper
python3 main.py -c 20 -a
```

### 步骤4：保存
- 保存为 `NewsScraper.app`

### 步骤5：设置定时启动
- 打开「系统设置」→「通用」→「登录项」
- 添加 `NewsScraper.app` 到登录项（可选）

## 方法四：使用Terminal手动设置（需要管理员权限）

打开终端执行以下命令：

```bash
# 加载launchd定时任务
launchctl bootstrap gui/$(id -u) /Users/zhuxingchong/Library/LaunchAgents/com.news.scraper.daily.plist

# 验证任务是否加载成功
launchctl list | grep news.scraper
```

如需停止任务：
```bash
launchctl bootout gui/$(id -u) /Users/zhuxingchong/Library/LaunchAgents/com.news.scraper.daily.plist
```

## 定时任务配置说明

### 任务配置文件
- 定时服务：`scheduler.py`（支持实时进度、双时间执行）
- 启动脚本：`start_scheduler.sh`
- 执行脚本：`run_daily.sh`
- plist文件：`~/Library/LaunchAgents/com.news.scraper.daily.plist`

### 执行时间
- 早上：8:30
- 下午：18:00

### 任务参数
- `-c 20`：每次抓取20条新闻
- `-a`：生成音频文件

### 输出目录
- 新闻JSON：`news/YYYY-MM-DD/tech_news_xxx.json`
- 音频文件：`news/YYYY-MM-DD/audio/新闻标题.wav`

### 项目结构
```
tech_news_scraper/
├── main.py           # 主入口
├── scraper.py        # 爬虫模块
├── news_to_audio.py  # 音频生成（调用audio_processing_module）
├── scheduler.py      # 定时任务服务（支持实时进度）
├── start_scheduler.sh# 后台启动脚本
├── run_daily.sh      # 执行脚本
├── news/             # 新闻存储目录
│   └── 2026-06-24/
│       ├── tech_news_xxx.json
│       └── audio/
├── scheduler.log     # 定时任务日志
└── cron.log          # 执行日志
```
