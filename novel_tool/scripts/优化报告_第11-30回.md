## 优化原则

### 1. 旁白叙述类
- **原格式**：空字符串或简单描述（如"平静"、"紧张"）
- **优化后**：复合描述格式 `情绪+状态+氛围`
- **示例**：
  - `""` → `"平和叙述，语气舒缓，如画卷般展开"`
  - `"平静"` → `"平静叙述，语气舒缓，如画卷般展开"`
  - `"紧张"` → `"紧张叙述，语速加快，营造紧迫感"`

### 2. 角色对话类
- **原格式**：简单情绪词（如"恭敬"、"兴奋"）
- **优化后**：结合 `情绪+语态+人物特质`
- **示例**：
  - `"恭敬"` → `"恭敬有礼，透着晚辈的谦和"`
  - `"恭敬询问"` → `"恭敬有礼，透着晚辈的谦和与求教之心"`
  - `"伶俐爽快"` → `"伶俐爽快，透着少女的机敏"`
  - `"轻喝"` → `"轻喝一声，声如洪钟"`
  - `"兴奋"` → `"兴奋，声音中透着按捺不住的喜悦"`
  - `"不服气"` → `"不服气，带着少年人的倔强"`

### 3. 特殊情绪类
- **严肃中带怜悯** → `"严肃中带怜悯，透着长者的慈悲"`
- **劝慰中带神秘** → `"温柔中带神秘，似有所指"`
- **故作神秘** → `"故作神秘，卖着关子"`

- **果断坦然** → `"果断坦然，透着洒脱"`
- **无奈但坚定** → `"无奈但坚定，透着决绝"`

### 4. 新增复合情绪
- **愤懑** → `"愤懑，压抑着怒火"`
