## 配音一致性规则

1. 同一小说内，同一角色一旦写入本表，后续所有章节必须严格复用同一个 `配音名`。
2. 生成剧本时，`roles_definition` 必须以本表为准，不能因为历史 JSON 或临时判断擅自改配音。
3. 新角色首次出现且本表没有记录时，先结合整部小说角色设定、当前章节人物气质和 `references/克隆音频角色列表说明.md` 选择合适配音，再把新角色补充到本表。
4. 角色分类可按小说实际情况调整，但表头字段必须保留：`角色名`、`配音名`、`角色性格说明`、`配音个性说明`、`使用范围`、`备注`。
5. 如果发现历史 JSON 与本表冲突，以本表为准，并在重新生成或优化时修正 JSON 中的 `roles_definition`。
